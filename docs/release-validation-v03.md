# Version 0.3.0 validation

Validated 20 September 2026. These are local computational and document checks, not external peer review, acceptance or customer validation.

## Scientific and numerical checks

- Three internal AI reviewers examined mathematical correctness, empirical/reproducibility claims and venue fit. Their initial critiques and final reports are retained in `docs/reviews/`. Final reviews found no blocking mathematical or numerical error within the reviewed scope. The IUI-oriented review judged the revised work plausible as a computational work-in-progress poster, not as a full research-paper contribution.
- The revision adds a deterministic parser baseline and a controlled precision/identification sweep. No additional paid model requests were made. The prior 7,200 recorded attempts, 7,183 valid responses and 17 retained transport failures remain unchanged.
- The parser's complete JSON output reproduced exactly, including both separately reported interval constructions, each resolving 7/9 conditions with zero incorrect resolutions. The parser reads supplied synthetic weights, validates the declared taxonomy, and does not access private intent labels during inference.
- An independent internal rerun reproduced all 14,400 controlled datasets: `replicates.csv`, `summary.csv` and `structural.json` matched byte for byte. The new public reproduction script was also run end to end and produced the same exact matches. Plot PDF/SVG metadata can vary; numeric equality does not depend on those timestamps.
- Sweep source, plan and output hashes match the recorded original execution. The compressed replicate archive expands to the expected hash. The new design records a pre-execution plan but is not externally preregistered.
- Sixteen existing compressed model-record archives passed compressed and expanded checksums. All four underlying model analyses already reproduced exactly for v0.2 and are unchanged in this release.
- The uncertainty controls distinguish structural identification from finite precision. The 98%, 98% and 96% nominal guarantees are disclosed as different; the methods are uncertainty-source ablations, not an equal-confidence ranking. Failures stay in unconditional denominators. Synthetic contrasts are not measured customer outcomes.

## Code and interface checks

- `make test`: **80 Python tests passed**, plus **14 investigator-instrument assertions** and core checks of **all 72 inspector conditions**.
- The inspector dataset regenerated byte for byte from its four source analysis files. Endpoint mixtures satisfy simplex and contrast checks. Evaluation-only truth is omitted from the viewer.
- Inspector browser QA covers **144 condition/viewport combinations** in Chromium, keyboard interactions, displayed data, failure counts, network isolation and overflow. No final browser errors or external requests were observed. See `inspector/qa-report.md`. This is software QA, not usability evaluation, PDF accessibility certification or human research.
- `scripts/reproduce_v3_results.py --verify-only` verifies artifacts and reruns the parser; the default also reproduces the complete simulation. Both commands passed locally without API calls.
- The first Linux CI run passed all original tests and artifact hashes but exposed a last-digit parser discrepancy: mean width `0.02284660696519887` versus macOS `0.022846606965198867`. The CI check now explicitly permits at most `1e-12` absolute error per finite float leaf and logs all differences. Schema, types, integer counts, decisions and provenance remain exact. Six additional regression tests protect these requirements. Local default reproduction remains exact; cross-platform numerical equivalence is not mislabeled as byte-exact reproduction.
- Credential-pattern scanning found no suspected credentials in repository candidates or expanded compressed records. `git diff --check` passed.
